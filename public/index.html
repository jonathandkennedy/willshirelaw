How to launch a campaign from this hub
1. Pick the practice → region → city below. Each chip is the page; click to preview, or use Copy URL for the final URL.
2. Set the ad group's Final URL to that page. Add this Final URL suffix at the campaign or account level so keyword, match type, device and campaign IDs land in every lead:
kw={keyword}&matchtype={matchtype}&campaignid={campaignid}&adgroupid={adgroupid}&creative={creative}&device={device}&network={network}&loc_physical_ms={loc_physical_ms}&utm_source=google&utm_medium=cpc&utm_campaign={campaignid}&utm_term={keyword}
3. Dynamic keyword headlines: with kw={keyword} in the suffix, the H1 adapts to the searched keyword (whitelist only — "attorney", "lawyer", "near me", "best/top", "free consultation", "abogado" → matching headline; anything else shows the control headline). Leads carry the keyword and a kw_variant event fires for GA4 segmentation.
4. Full list with phones and office: campaign-urls.csv (import into Google Ads Editor) · CAMPAIGN-URLS.md.
